NM_SaleForce
🚗 Garage & Customer Management System (Salesforce)
📌 Overview
This project is a Salesforce-based Garage & Customer Management System developed as part of a college project at PPG College of Arts and Science.

It allows garages to efficiently manage:

Customer details
Vehicle information
Appointments & services
Billing & feedback
The system uses Salesforce custom objects, validation rules, roles, dashboards, and duplicate management to ensure accuracy and efficiency.
✨ Features
🔹 Custom Objects for Customers, Vehicles, Appointments, Billing, and Services
🔹 Validation Rules (e.g., valid vehicle number plate, rating < 5)
🔹 Duplicate Management to avoid duplicate records
🔹 Role Hierarchy & Sharing Rules for secure data access
🔹 Reports & Dashboards for insights and feedback
🔹 Public Groups & Profiles to manage teams
🛠️ Tech Stack
Salesforce Lightning Platform
Custom Objects & Schema Builder
Validation Rules & Triggers
Profiles, Roles & Sharing Rules
Reports & Dashboards
🚀 Setup Instructions
Sign up for a free Salesforce Developer Edition.
Clone or download this repository.
Import metadata into your Salesforce Org.
Configure:
Custom Objects (Customer, Appointment, Vehicle, Service Records)
Validation Rules & Duplicate Rules
Roles & Sharing Rules
Test by creating sample records and generating reports.
